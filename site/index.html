How bad are things right now?

A Grafana panel for the office television. The screen gets noisier as more things break. Nothing healthy is ever drawn, so you can tell how bad it is from across the room without reading a word.

Install it See the source

Read it from ten metres

The screen represents attention, not infrastructure. All of it goes to whatever deserves attention now.

  1. Nothing wrongQuiet. A mark drifts around the screen.
  2. One problemIt takes the whole screen.
  3. Two problemsThe screen splits.
  4. MoreBoxes fill the screen, the worst problem biggest.
  5. Lasting longerIts box grows and its colour strengthens.
  6. FixedThe box goes and the others take the space.

When nothing is wrong

The screen goes quiet and a screensaver takes over: the bouncing DVD logo, the Windows XP 3D Text rebuilt in CSS, or a split-flap clock. A calm screen means a calm estate. There is no wall of green for anyone to learn to ignore.

Feed it one number

One number per service and which label names it. Out of the box it expects availability, good events over total events, which is the shape most SLOs already come in. Sloth and Pyrra recording rules work untouched.

Install

Grafana 12.3 or newer. It is not in the Grafana catalogue yet, so the files go in by hand, which takes about two minutes. 

unzip triwats-noiseisbad-panel-*.zip -d /var/lib/grafana/plugins/

Allow the unsigned plugin, restart Grafana, add a panel and set Demo to Shipping Incident to watch it work before pointing it at anything real. The install guide has every step.
