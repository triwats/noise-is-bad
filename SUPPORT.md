# Getting help

**The board is quiet when it should not be.** Check the warning level, the critical level and the
direction against [`docs/metrics.md`](docs/metrics.md). A threshold the data can never cross leaves
the screen calm through an outage, and that is the commonest report by far.

**Setting it up.** [`docs/install.md`](docs/install.md) and
[`docs/getting-started.md`](docs/getting-started.md) go from nothing to a board on the wall.

**Something is broken.** [Open an issue](https://github.com/triwats/noise-is-bad/issues/new/choose).
The template asks for the query and a few rows of what it returns, which is usually enough to see
what happened.

**A security problem.** Not in an issue, please. See [`SECURITY.md`](SECURITY.md).

This is maintained by one person in their own time. Answers may take a few days.
